CALIBRATION REPORT
==================
Date: 2026-02-20
Device: NVIDIA Grace Hopper (Unified Memory Architecture)

User Observation Data:
----------------------
Target (GB) | Observed (GB) | Offset (GB) | Factor
10.0        | 19.60         | +9.60       | 1.96x
30.0        | 40.85         | +10.85      | 1.36x

Analysis:
---------
1. The "Factor" decreases as load increases, confirming a FIXED OVERHEAD model rather than a simple multiplier.
2. The fixed overhead is approximately 10-12 GB (System OS + Driver Reservation + Background Apps).
3. The "Overshoot to 90GB" observed during the 50GB test indicates significant dynamic memory allocation by the GPU driver before stabilization.

Shield Calibration Actions:
---------------------------
1. REMOVED the incorrect "1.44x" multiplier from the code. This was causing under-reporting for small loads and over-reporting for large loads.
2. ENABLED "System Total" monitoring as the primary trigger for Unified Memory.
   - The Shield now reads exactly what the user sees (Total System Memory Usage).
   - Example: If User sees 62GB, Shield sees 62GB.
3. UPDATED "Victim Selection" logic:
   - When System Memory > Threshold, the Shield will now prioritize killing GPU processes (via NVML list) even if their reported individual usage is low (0MB or small RSS), solving the "Hidden Memory" issue.

Result:
-------
The Shield is now calibrated 1:1 with the User's System Monitor.
Current Threshold: 35000 MB (35 GB).
- A 30GB Load (resulting in ~41GB Total) WILL trigger the Shield.
- A 10GB Load (resulting in ~20GB Total) WILL NOT trigger the Shield.
